# 多 USV 集群 RL 重训方案

## 1. 目标与边界

### 1.1 目标

本方案用于将当前 RL 避让能力从“单船标准会遇验证可用”升级为“多 USV 集群场景可部署”。训练后的策略需要同时满足以下约束：

- 支持 2 到 5 条 USV 的动态会遇与连续会遇。
- 避让过程满足 COLREGS 的基本让路规则，特别是对遇、右舷交叉、追越三类规则场景。
- 避让过程中不允许倒车。
- 保持现有主导航链路不被破坏，策略应作为局部避让层而非替代全局导航。
- 在多船冲突中优先保持平滑、连续、可恢复的航迹，不出现明显抖动、长时间僵持和频繁左右摆。

### 1.2 非目标

- 不追求纯端到端替代 AMPC/MPC 主导航。
- 不追求无规则约束的自由博弈型多智能体策略。
- 不在第一阶段处理狭窄航道、靠泊、动态障碍混合、风浪扰动耦合等复杂任务。

## 2. 当前方案与真实需求的差距

当前仓库中的 RL 训练链路更接近“单个 ego 船在标准会遇中的残差修正学习”，而真实业务需求是“多船集群连续会遇中的规则一致避让”。两者存在以下关键差距：

- 训练场景以单邻船标准会遇为主，尚未系统覆盖 2 到 5 船的多邻船交互。
- teacher 数据中存在负线速度动作，训练分布默认允许减速甚至倒车。
- 奖励函数主要覆盖防碰、进度和平滑，尚未把 COLREGS 合规性建成强约束目标。
- 在线部署虽然可以通过控制器钳位阻止倒车，但如果训练分布不修复，策略仍会持续产生不合理动作并造成效率损失。

因此，本次重训不是简单增加样本量，而是重新定义任务。

## 3. 推荐控制架构

### 3.1 总体原则

建议采用“规则约束 + 局部 RL 残差”的分层架构，而不是纯 RL 接管避让决策。

- 全局/主导航：继续由现有 AMPC/MPC 跟踪目标航迹。
- 规则层：根据相对方位、会遇类型、直航权/让路权给出 COLREGS 合法动作域。
- RL 层：只在合法动作域内输出局部平滑修正，用于提升丝滑性、恢复性和多船协调效果。
- 安全投影层：将 RL 输出投影到“无倒车、合法转向侧、有限角速度、有限减速幅度”的安全集合。

### 3.2 不建议继续使用的动作定义

当前“线速度残差 + 角速度残差”的双通道残差不适合作为集群部署的长期方案，主要因为：

- 容易学出负线速度。
- 多船交互时容易通过刹停来逃避风险，而不是学会让路路径。
- 与主导航的速度规划耦合过强，容易破坏到点逻辑和航迹恢复。

### 3.3 推荐动作空间

按优先级推荐两种方案。

#### 方案 A：仅输出角速度残差

动作定义：

- $a = [\Delta \omega]$

特点：

- 最安全。
- 与“不允许倒车”天然一致。
- 最符合“RL 只负责避让形状，主导航负责前进”的职责分工。

适用阶段：

- 第一阶段首选。
- 用于快速建立稳定、可解释、可部署的多船避让基线。

#### 方案 B：输出非负速度缩放 + 角速度残差

动作定义：

- $a = [s, \Delta \omega]$
- 其中 $s \in [s_{min}, 1.0]$，建议 $s_{min} \in [0.2, 0.4]$

控制解释：

- 最终前进速度 $v = s \cdot v_{nav}$
- 严禁 $v < 0$

特点：

- 保留一定的速度调节能力。
- 能在近距离高风险时减速，但不会倒车。

适用阶段：

- 第二阶段或在方案 A 稳定后升级。

## 4. 状态与观测设计

### 4.1 保留的基础观测

- 本船到目标距离。
- 本船航向误差。
- 本船当前前进速度。
- 主导航原始前进速度与角速度。
- 邻船相对位置、相对速度、相对方位、距离。

### 4.2 建议新增的规则相关特征

为了让策略更容易学到 COLREGS，不建议完全依赖网络自己从几何量中隐式发现规则关系。建议显式加入以下特征：

- 每个邻船的会遇类别标签：对遇 / 交叉 / 追越 / 不构成规则会遇。
- 每个邻船的责任角色：本船让路 / 本船直航 / 不确定。
- 每个邻船的建议规则侧：右转 / 保持 / 左转禁用。
- 最危险邻船的 TTC 近似值。
- 当前是否处于连续会遇或多冲突叠加状态。

### 4.3 多邻船编码策略

建议保留“按风险排序取前 $K$ 个邻船”的结构，$K$ 建议从 3 提升到 5。排序依据建议使用：

- 最小预测碰撞时间优先。
- 距离与闭合速度联合风险优先。

同时增加聚合特征：

- 最近邻风险。
- 右舷最高风险。
- 左舷最高风险。
- 前向扇区风险总量。

## 5. 场景设计

### 5.1 核心原则

场景设计要从“标准规则会遇”逐步扩展到“连续会遇与局部拥挤”，不能直接跳到随机多船乱战。

### 5.2 场景族划分

#### A. 单邻船规则基线场景

用途：建立基础 COLREGS 行为。

- 对遇：双方应右转通过。
- 右舷交叉：本船让路，优先右转并适度减速。
- 左舷交叉：本船直航，除非接近紧急状态。
- 追越：追越船绕行，被追越船保持稳定。

#### B. 双邻船连续会遇场景

用途：训练“避完第一船后还能恢复主航向，并处理第二次冲突”。

- 对遇 + 右舷交叉。
- 追越 + 对遇。
- 左右两侧非对称交叉。
- 一近一远双风险邻船。

#### C. 三船局部冲突场景

用途：训练局部拥挤中的风险排序和规则一致性。

- 三船十字穿越。
- 两船同向前方 + 一船右舷切入。
- 编队边缘船与外部目标船交汇。
- 本船同时面对一个让路责任和一个直航责任对象。

#### D. 四到五船集群场景

用途：训练群体干扰下的稳定避让。

- 多船交汇点疏散。
- 编队重组过程中的连续局部避让。
- 多船随机起点、不同终点、局部密度上升场景。

当前仓库第一版 5 艘标准重训场景已实现以下 3 个 dense 场景名，可直接用于数据采集与 PPO 重训：

- `five_usv_dense_head_on`: 1 艘对遇 + 2 艘交叉 + 1 艘追越背景船。
- `five_usv_dense_crossing`: 2 艘右舷交叉风险船 + 1 艘偏置对遇 + 1 艘左舷保持船。
- `five_usv_dense_overtaking`: 2 艘前方慢船 + 1 艘右舷切入船 + 1 艘远端对遇船。

这三类场景统一按“1 艘本船 + 4 艘邻船”构造，并以 4m 冲突半径作为第一阶段有效避让训练窗口。

#### E. 干扰与鲁棒性场景

用途：降低 sim-to-sim 和 sim-to-real 失配风险。

- 观测延迟。
- 邻船状态抖动。
- 控制频率波动。
- 初始航向与目标距离随机化。

### 5.3 场景采样原则

- 规则样本均衡：避免 head-on 远多于 crossing/overtaking。
- 风险强度分层：远距、中距、近距都要覆盖。
- 连续会遇比例逐步提高，不在初始阶段过高。
- 直航权场景要足够多，防止策略学成“见船就躲”。

## 6. 奖励设计

### 6.1 设计原则

奖励函数的角色不是替代规则，而是把规则目标转成可优化信号。建议采用“安全优先、规则次之、效率再次、平滑最后”的层次。

### 6.2 建议奖励项

#### 安全项

- 碰撞重罚：发生碰撞立即终止。
- 近失惩罚：进入 near miss 距离强惩罚。
- TTC 风险惩罚：对小 TTC 的状态增加持续惩罚。
- 提前避让塑形：风险项应在 5m 左右开始起效，而不是等到 4m 内才骤然介入。

#### 规则项

- 非法侧转向惩罚：在应右转时左转，重罚。
- 直航船过度主动变向惩罚：避免本应保持航向时过度规避。
- 让路失败惩罚：本船负有让路责任但仍维持闭合趋势，重罚。
- Rule 17 紧急兜底豁免：直航船在危险逼近时允许采取避险动作，但不奖励过早规避。

#### 效率项

- 朝目标进度奖励。
- 脱离冲突后恢复主航向奖励。
- 路径拉长惩罚：避免大幅绕远。
- 长时间停滞惩罚。
- 冲突期间低速惩罚：避免通过过早刹停把避让学成“一停一顿”。

#### 平滑项

- 角速度变化率惩罚。
- 控制抖动惩罚。
- 频繁换侧惩罚：在一次会遇中避免左右反复摇摆。
- 保持性约束：已经开始右转绕行后，优先连续完成规避，不要出现走走停停和转一下又回正的断续行为。

### 6.3 硬约束优先于软奖励

以下要求不建议只靠奖励学习，必须进入动作投影或安全过滤：

- 禁止倒车。
- 最大角速度和角加速度限制。
- 非法转向侧禁止。

## 7. 课程学习方案

### 阶段 0：规则 teacher 与数据集重建

目标：生成符合真实业务约束的新 teacher 数据。

要求：

- teacher 绝不输出倒车动作。
- teacher 遵守 COLREGS 基本规则。
- teacher 在冲突解除后能够回归主航迹。

产出：

- 新版 scripted teacher。
- 新版 BC 预训练数据集。

### 阶段 1：单邻船规则学习

目标：先把单次会遇做稳。

训练内容：

- 对遇、右舷交叉、左舷交叉、追越。
- 单动作域推荐优先用“仅角速度残差”。

门槛：

- 无碰撞。
- 无倒车。
- 规则方向正确率达到上线门槛。

### 阶段 2：双邻船连续会遇

目标：处理连续冲突与风险排序。

训练内容：

- 两次规则会遇串联。
- 一近一远风险叠加。
- 让路后重新并线与回归目标。

门槛：

- 不出现持续僵持。
- 冲突解除后能恢复前往目标。

### 阶段 3：三船集群训练

目标：建立最小可用集群能力。

训练内容：

- 三船交汇。
- 两侧来船。
- 编队边缘船与外部船交会。

门槛：

- 主规则场景达到集群上线门槛。
- 不出现高频左右切换。

### 阶段 4：四到五船域随机化

目标：提升泛化与鲁棒性。

训练内容：

- 多船随机初始化。
- 控制周期与观测噪声扰动。
- 目标点密度和交通密度随机化。

门槛：

- 通过鲁棒性和压力测试门槛。

### 阶段 5：在线 SITL 闭环验收

目标：确保离线训练结果在真实 SITL 控制链中成立。

训练后验证内容：

- 单船 RL + 其余规则船。
- 单船 RL + 多邻船真实中继。
- 逐步扩展到多条船同时启用 RL，但不作为第一上线目标。

## 8. 训练方法建议

### 8.1 推荐流程

建议采用三步法：

1. BC 预训练。
2. DAgger 或离线纠偏数据增强。
3. PPO 小步在线微调。

### 8.2 为什么不建议直接 PPO 从零开始

- 多船规则场景探索成本高。
- 纯探索容易学出“停住不动”或“靠极端减速避险”的局部最优。
- 先用规则 teacher 打底，可以明显降低训练不稳定性。

### 8.3 是否需要多智能体 RL

第一阶段不建议直接进入全多智能体联合训练。更务实的路线是：

- 先训练单个 ego 在多邻船背景中的策略。
- 邻船使用规则控制器或脚本策略。
- 在该方案成熟后，再评估是否需要双智能体或多智能体对抗/协同训练。

## 9. 验收指标

### 9.1 安全指标

- 碰撞率：$0\%$ 作为上线目标。
- 近失率：按场景设定阈值，例如小于 $1\%$。
- 最小安全距离分位数：P5、P50、P95 都需统计。

### 9.2 规则指标

- 对遇右转合规率。
- 右舷交叉让路合规率。
- 追越绕行合规率。
- 直航船保持率。
- 非法左转/非法抢道次数。

建议上线前关键规则场景合规率不低于 $95\%$，核心场景目标为 $98\%$ 以上。

### 9.3 效率指标

- 到达成功率。
- 平均到达时间。
- 路径拉长比：$\text{actual path length} / \text{nominal path length}$。
- 冲突解除后的恢复时间。

### 9.4 平滑性指标

- 平均角速度绝对值。
- 角速度变化率 RMS。
- 横摆换向次数。
- 单次会遇中的转向侧切换次数。

### 9.5 业务硬门槛

以下门槛建议作为硬验收条件：

- 0 次倒车。
- 0 次碰撞。
- 关键规则场景合规率不低于 95%。
- 三船主场景到达成功率不低于 90%。
- 五船压力场景到达成功率不低于 80%。

## 10. 推荐实验矩阵

建议至少形成以下实验对照：

- Baseline 1：零残差 / 无学习避让，仅保留导航主链。
- Baseline 2：现有单邻船 RL 模型。
- Candidate A：仅角速度残差 + 新 teacher。
- Candidate B：非负速度缩放 + 角速度残差 + 新 teacher。
- Candidate C：Candidate A + PPO 微调。
- Candidate D：Candidate B + PPO 微调。

每个 candidate 都需要在 1 船、2 船、3 船、5 船四类测试集上比较。

## 11. 推荐实施顺序

### 里程碑 M1

- 重写 teacher。
- 去掉训练中的负线速度动作。
- 完成单邻船 BC 数据集重建。

### 里程碑 M2

- 将 RL 动作改为“仅角速度残差”。
- 完成阶段 1 和阶段 2 的训练与回归测试。

### 里程碑 M3

- 扩展到三船场景。
- 加入显式 COLREGS 奖励与非法动作投影。

### 里程碑 M4

- 完成四到五船域随机化训练。
- 完成 SITL 多船验收。

## 12. 最终建议

如果目标是“让 RL 真正承担多 USV 集群避让，并且丝滑、合规、绝不倒车”，建议采用以下落地路线：

1. 立即停止继续沿用允许负线速度的 teacher 数据。
2. 第一阶段把 RL 动作收缩为“仅角速度残差”。
3. 先把三船集群作为首个上线目标，而不是直接追求五船全量上线。
4. 将 COLREGS 合法动作域做成安全投影，不把规则完全交给奖励函数自行学习。
5. 在离线指标达标前，不建议让多条船同时启用 learned residual 策略作为默认运行模式。

这个方案的核心思想是：

- 规则负责正确性下界。
- RL 负责平滑性和效率上界。
- 安全投影负责部署可控性。

## 13. 当前仓库实现状态

截至当前版本，仓库已经具备“角速度残差优先”的第一阶段重训入口，适合作为多 USV 集群 RL 重训的起始实现。

### 13.1 已完成的基础能力

- 控制器默认禁止 RL 产生倒车。
- 训练环境支持 `action_mode=angular_only`。
- teacher 数据采集脚本支持输出单动作通道数据集。
- teacher 数据采集脚本新增 `cluster_colregs_v1`，面向 5 船密集场景聚合多邻船风险，并只输出右转、零倒车残差。
- PPO 训练脚本支持 `angular_only` 动作模式。
- 评估脚本支持按模型动作维度自动切换 `action_mode`。
- 在线推理节点兼容 1 维和 2 维策略输出。

### 13.2 推荐的第一阶段命令

当前标准重训场景统一按 5 艘 USV 设计：1 艘本船 + 4 艘邻船，要求策略在 4m 冲突半径内完成有效避让。
同时把最小间距 0.5m 作为硬约束：训练终止、teacher 应急偏置和评估验收都按“不低于 0.5m”执行。

#### 采集角速度残差 teacher 数据

```bash
cd ~/usv_workspace
. ./.venv/bin/activate
source /opt/ros/jazzy/setup.bash
source ./install/setup.bash

```
